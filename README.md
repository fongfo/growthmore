# growthmore

Bank white-label rewards and investment learning product.

## Build Target

The user-facing product is a mobile app first. Use `apps/mobile` with Expo,
React Native, and TypeScript for app development. Do not create a Web/H5 user
client unless a Jira issue explicitly changes the scope.
